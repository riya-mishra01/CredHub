# CredHub

CredHub is a frontend website designed to manage micro-credentials, certifications, and achievements in one place.

## Live Demo
Link: https://misra7060-ux.github.io/CredHub/

## Key Features
- DigiLocker Integration: Seamless connection to access government-issued documents.
- Secure Storage: Structured concept for credential safety.
- Instant Verification: Verification interface with OTP-based authentication.
- Easy Sharing: One-click sharing for employers and institutions.

## Tech Stack
- HTML: For website structure.
- CSS: For clean card designs and mobile layout.
